# Timeline

For architecture roadmaps and evolution plans.

## Syntax

```
timeline
  title Architecture Evolution Roadmap
  section Phase 1 - Foundation
    Q1 2024 : API Gateway deployment
             : Service mesh setup
  section Phase 2 - Migration
    Q2 2024 : Monolith decomposition
             : Event-driven refactor
  section Phase 3 - Optimization
    Q3 2024 : Auto-scaling
             : Observability platform
```

Multiple events per time period are added with `: event` on indented lines.
