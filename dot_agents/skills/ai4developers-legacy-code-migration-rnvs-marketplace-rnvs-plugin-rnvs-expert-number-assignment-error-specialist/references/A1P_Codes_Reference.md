## Architecture Overview

The A1P error codes are generated by the RNVS data synchronization process that compares three systems:
- **RNPS**: Rufnummernportierungs-System (Number Porting System)
- **RNVS**: Rufnummernverwaltungs-System (Number Management System)
- **ANDI**: ANDI Database (external system from BNetzA)

### Code Generation Mechanism

**Matrix-Based Generation** (123 codes):
Most A1P codes (A1P000-A1P163, excluding A1P098/A1P099) are **dynamically generated** based on a decision matrix stored in database table `t_prm_pruefmatrix`. The matrix evaluates:
- RNPS state (filled with TNB, filled with 199c07, or absent)
- RNVS state (not present, free, or occupied with owner)
- ANDI state (not present, DTAG assignment, TNB assignment, 199c07 assignment)
- Order status (current, past, future, export)
- Porting status (unconfirmed import/reimport, unconfirmed export)

**Hardcoded Constants** (2 codes):
- **A1P098**: FC_ABGL_PS_2 - RNPS phone number exactly 11 digits in 2-digit area code
- **A1P099**: FC_ABGL_PS_1 - RNPS phone number greater than 11 digits
