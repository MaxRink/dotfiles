# Persist

Version these artifacts in dotfiles:

| Artifact | Target | Notes |
|---|---|---|
| Sanitized Codex config | [`/dot_codex/config.toml`](../../config.toml) | No tokens, no raw auth, compact trusted roots, disabled risky MCPs by default. |
| Approval rules | [`/dot_codex/rules/default.rules`](../../rules/default.rules) | Keep only reviewed prefix rules. |
| Curated skills | [`/dot_agents/skills`](../../../../dot_agents/skills/) | Include scripts and references; exclude caches and generated bytecode. |
| OKF knowledge | [`/dot_codex/knowledge/okf`](../index.md) | Human-readable, parseable, diffable knowledge bundle. |
| Installation scripts | Existing `run_*` scripts | Scripts should be idempotent and avoid embedding secrets. |

# Exclude

Do not copy these into dotfiles:

| Artifact | Reason |
|---|---|
| `~/.codex/auth.json`, `~/.codex/.credentials.json` | Authentication material. |
| `~/.codex/*sqlite*`, `~/.codex/state*`, `~/.codex/logs*`, `~/.codex/goals*` | Local runtime state and histories. |
| `~/.codex/history.jsonl`, shell snapshots, rollout JSONL | Raw session material can include secrets or sensitive project context. |
| `~/.codex/cache`, `~/.codex/.tmp`, packages, model caches | Rebuildable runtime cache. |
| Raw browser captures, Confluence HTML exports, PSA ZIP/XLSX/PDF downloads | They can contain transient session tokens or access-scoped content. Keep curated summaries in project repos only when intentionally reviewed. |
| Kubeconfigs, private keys, PATs, API keys, bearer tokens | Secrets must stay in local secret stores or enterprise-managed vaults. |

# Validation

Run the curation validator after changing this repo:

```bash
python dot_agents/skills/codex-knowledge-curation/scripts/validate_codex_persistence.py .
```

The validator checks OKF frontmatter, reserved files, cache files, raw state names, and obvious secret-token patterns.
